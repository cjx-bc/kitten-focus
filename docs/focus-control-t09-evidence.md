# T09 ordinary independent lock evidence

Date: 2026-11-15. Ticket: #10. Scope: ordinary locks; strict locks remain T10.

The existing SQLite `active` owner now distinguishes independent locks with native-created `kind: lock`. FocusEngine ignores these sessions; FocusControl directs lock lifecycle work to LockEngine, while the existing active checks exclude focus, running rest, replacement/import and upgrade restore. Native focus admission strips caller-supplied lock kind/configuration identity. No second focus authority or focus record table was introduced.

Reusable `AppData.lockConfigurations` save name, integer minutes (1–1440), and the same source-tagged global/custom whitelist contract used by items. CatFocus.startLock accepts only a saved configuration ID, resolves it natively and freezes the chosen whitelist at start. An empty custom list replaces the global list. Native application connection is required even when study preference is off. Browser start reports Android support required.

Locks share the existing application controller and recovery journal. Observe remains read-only; remaining time uses monotonic time on the same boot. Native recreation retains the deadline, and reboot interrupts using the last checkpoint without counting the gap. Expiry and confirmed early end atomically append `lockHistory` and release active ownership, alarms and restriction duties. No focus records, statistics, calendar focus or automatic rest result. Active recovery withdraws protection without stopping the lock countdown; failed cleanup retains the shared repair entry.

UI uses existing Sheet, Icon, application picker, colors, typography and five main tabs. My settings links to the separate lock page; tasks show a current-lock return entry. Start displays configuration/permissions, early end requires a Sheet confirmation and cancellation keeps the session. Warm/cold application-control notification and block return choose the lock owner; finished lock notifications use a dedicated return flag. Subsequent T10/T16 can tighten lock timing and main-route behavior independently.
