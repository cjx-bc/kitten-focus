# 小猫专注：第一版产品规格

版本：已确认需求基线 v1。日期：2026-11-14。状态：用户已在 Q32 回复“确认”，包括指标补充与实现质量约束；现进入实现与验证阶段。

来源：[访谈记录](requirements.md)、[业务术语](../GLOSSARY.md)、[架构决策](adr/)、[界面参考](references/README.md)。本规格汇总最终决定，已吸收对 Q7、Q11 和 Q29 的修订。

## 1. 产品与交付范围

小猫专注是面向学生日常学习的安卓应用。第一版围绕“安排时间、选择常驻待办、专注、查看实际投入”提供完整本地流程，免登录、离线可用。

底部导航固定为：**待办｜日历｜小猫｜统计｜我的**，默认进入待办页。专注是独立全屏页面。

| 模块 | 第一版交付 |
| --- | --- |
| 待办 | 主题与可反复使用的子待办，编辑、排序、删除、开始专注 |
| 日历 | 个人日程、学生课表、计划与实际时间轴 |
| 小猫 | 仅显示“小猫还未入驻”，保留底部导航入口 |
| 统计 | 实际专注时长、次数、占比、趋势、时段分布、记录 |
| 我的 | 专注与提醒偏好、参考设计支持的显示偏好、本地备份恢复、关于 |

第一版不包含宠物养成、商店、金币与经验、AI 助手、强力锁机、账号和云同步、App 使用统计、起床/睡眠打卡、打断原因统计。自动循环番茄和自动休息、手动补录或修改专注时长也不纳入首版。

用户未提出硬性截止日期，按单人开发、分阶段产出可安装版本规划。交付安卓 APK、全部源码和中文运行安装说明，以安卓真机离线流程验收。

## 2. UI 基准

整体外观全面参考 iOS「小鸡专注」，包括配色、字体气质、数字、图标、圆角、留白、按钮、卡片、弹窗与背景表现。页面功能和导航按本规格组织。原始资料已保存至 [references](references/README.md)。

Q29 的最终决定是“参考小鸡专注来”。因此不能将助手原先建议的“默认跟随系统、统一纯色背景、背景相关功能统一延期”写成用户已确认的方案。外观设置和背景的具体表现应在参考资料对照中细化，未覆盖状态按同一设计语言补齐并在界面阶段验收。

商店展示图的宣传文字、手机外框、叠放效果不作为应用内部界面。仅有图标或宣传描述不能据此扩大首版功能范围；宠物、AI 和锁机的排期以本规格为准。

## 3. 待办

### 3.1 主题与子待办

- 主题包含名称、颜色，支持创建、编辑、排序、展开和折叠。
- 子待办属于一个主题，包含标题、可选备注、计时模式、倒计时时长，支持创建、编辑、排序和删除。
- 子待办是长期保留的专注事项，没有完成状态、完成勾选、已完成列表、每日重置或计划日期。安排时间由日历承载。
- 子项展示名称、模式/时长、今日专注次数、今日专注时长及开始按钮；提供自由专注入口。
- 进行中的专注在待办顶部提供返回入口；再次进入同一专注不会新建第二条。

### 3.2 历史与删除

- 改名不拆散同一事项的累计统计，历史记录显示当时名称与实际时长。
- 移动事项到其他主题，只改变之后的归属，旧记录仍属于发生时的主题。
- 删除待办不删除历史专注和统计；关联日程保留标题和时间，解除待办关联。
- 删除主题时，可连同删除下属待办，或先移动到其他主题；历史专注仍保留。
- 删除专注记录才会移除该条实际投入，并同步更新统计与日历实际记录。

## 4. 专注

### 4.1 开始与控制

- 可从子待办开始，自动关联事项与主题；也可直接自由专注，不强制创建待办。
- 支持正计时和倒计时。倒计时默认 25 分钟，按分钟修改，提供 25/45/60 分钟快捷项。
- 同时只能有一条未结束的专注，暂停中的专注也占用该名额。
- 专注页显示事项名称、大号计时、暂停/继续和结束，隐藏底部导航。
- 返回待办、切换应用、锁屏均不自动结束计时；通过待办顶部入口恢复界面。
- 暂停不累计实际专注时间，继续后恢复累计。

### 4.2 结束状态

| 状态 | 条件 |
| --- | --- |
| 正常结束 | 倒计时达到目标，或正计时由用户手动结束 |
| 提前结束 | 倒计时达到目标前由用户主动结束 |
| 中断 | 设备重启使未结束的专注终止 |

结束后展示实际专注时长、暂停时长与结束状态，可再次开始或返回待办。再次开始形成新记录，原记录保留。专注结束不会完成、删除待办或修改原日程。

倒计时到点即结束，打开结果页或收到提醒的延迟不应增加其实际专注时长。首版不自动接续下一轮或休息。

### 4.3 恢复与持久化

- 同次开机内意外退出后，重新打开恢复原会话并补算经过时间；若倒计时已到点，应恢复为已结束状态。
- 设备重启后标记中断，保留最后已保存的实际时长，不把重启间隔算入。
- 保存运行与暂停区间，保证时间轴和时段分布能够扣除暂停时间。
- 调整系统日期时间不直接改变同次开机内已经过的专注时长。
- 历史记录支持查看和删除，不支持手工补录和修改时长。同一专注只保存一次；零实际时长不产生统计次数。

## 5. 日历与课表

### 5.1 页面组织

- 日历页内提供“日程/课表”切换。
- 日程顶部显示一周日期条，可展开月历；下方切换计划与实际时间轴。
- 课表采用一周时间轴，按节次排列课程，可切换周次。
- 计划和实际分别保存；专注不会改写计划，课程或日程也不自动产生已专注时长。

### 5.2 个人日程

- 包含标题、起止时间、可选备注和可选子待办关联。
- 支持单次、全天、跨天和按周重复。
- 与其他安排时间冲突时提示，但允许保存。
- 重复日程的修改或删除支持“仅本次”和“整组”。
- 日程和待办各自独立：可以只排课程或个人事项，也可以只建待办而不排时间；建立关联不复制第二份待办。

### 5.3 学期与课程

- 支持多个学期，选择一个当前学期；旧学期保留查看。
- 每周从周一开始，以所选周一作为学期第一周起点；总周数可配置。
- 配置每天各节课的时间。节次起止在同一天内，开始早于结束。
- 课程配置星期、节次、起止周、单双周，教师和教室可选。
- 支持对某一次课程停课或调课，不影响其他周。
- 首版通过手动录入配置，不自动识别课表图片或推断节假日调课。

### 5.4 时间规则

日程按设备当地时间安排。历史按发生时当地日期归属，切换时区不改写旧记录。周以周一开始，月和年采用自然月、自然年。

## 6. 统计与记录

### 6.1 结构

提供日、周、月、年、累计切换，包含总时长、次数、专注天数、平均每次时长、主题/子待办占比、趋势、时段分布和历史记录入口。自由专注单独分类。

### 6.2 已确认的计算规则

- 按实际运行时长累计，暂停时间不计；正常结束、提前结束和中断均保留已经投入的实际时长。
- 不足一分钟也保留，不因显示单位取整而丢弃；较短记录可显示秒。
- 每条正实际时长的记录计一次，次数归开始日。
- 跨午夜时长按实际发生日期分配；时段分布按实际运行区间分配。
- 待办改名不拆散同一事项的累计，移动主题不回写旧主题，删除待办不清空历史；删除记录才调整统计。

### 6.3 已确认的指标定义

“专注天数”指筛选范围内存在正实际专注时长的日期数。“平均每次时长”按筛选范围内开始的完整专注记录计算；没有此类记录时显示“—”。总时长跨天拆分，次数归开始日。

例如一条记录从 23:50 到次日 00:20：首日总时长 10 分钟、次数 1，次日总时长 20 分钟、次数 0；若没有其他记录，首日的完整单次平均为 30 分钟，次日单次平均显示“—”。累计范围仍为 30 分钟、1 次。

## 7. 我的、提醒与本地数据

- 我的包含专注默认设置、显示/声音偏好、本地备份恢复和关于；外观项按第 2 节对照参考。
- 专注中提供计时通知，到点可播放声音和振动，并允许关闭。
- 日程和课程提醒默认关闭，逐项开启后默认提前 10 分钟。
- 备份文件包含全部已保存业务数据与设置。恢复整体替换当前数据，展示备份日期并确认，恢复前必须结束当前专注；不做合并。

下列为随最终规格审阅的实现质量约束：提醒权限被拒绝时核心功能继续可用，清楚显示提醒未开启并提供设置入口；损坏或不兼容的备份不覆盖当前数据，校验成功并确认后才执行整体恢复。未结束的专注不作为备份中的可运行状态恢复。

## 8. 技术分工与实施顺序

| 层级 | 已选技术与职责 |
| --- | --- |
| 页面 | Vue 3、TypeScript、Vite、Vue Router、Pinia |
| 安卓桥接 | Capacitor；Java 与 Android SDK 承接计时状态、系统通知等能力 |
| 本地数据 | SQLite，保存首版完整业务数据 |
| 图表 | ECharts，页面和数据离线可用 |
| 后续服务端 | Java 21、Spring Boot、MySQL；账号与云同步阶段接入 |
| 视觉资源 | SVG / 图片、CSS 动画；首版无宠物养成实现 |

实施建议按“最小安卓工程及 Java 桥接验证 → 待办与可靠专注 → 日历课表 → 统计与备份 → 界面逐页对照、真机回归与打包”推进。具体依赖版本、最低系统和通知调度策略在实际工程中核验；技术选型不等同于已经通过兼容性测试。

## 9. 验收场景

1. 离线启动，创建主题和子待办；反复专注后事项仍保留，无完成勾选。
2. 自由专注和关联待办的两种模式都可启动；存在未结束会话时不重复创建。
3. 暂停、继续、返回待办、切换应用和锁屏后恢复，实际时长符合规则；倒计时到点不因结果页延迟打开而超计。
4. 正计时正常手动结束、倒计时提前结束、意外退出恢复和设备重启中断，状态与已保存时长正确。
5. 编辑、移动或删除事项后历史与累计仍正确，关联日程按约定保留；删除记录后日历实际与统计同步变化。
6. 手动建立单次、全天、跨天和重复日程，验证冲突提示、仅本次/整组编辑和待办关联。
7. 设置学期、周次、节次、单双周课程；切周查看并进行一次停课或调课；旧学期可查看。
8. 对照已知记录检查短时、暂停、跨日、分类、次数和趋势；计划不被实际覆盖。
9. 导出并恢复完整备份，检查数据与设置；错误文件不覆盖现有数据，未结束专注时不能恢复。
10. 小猫页仅显示“小猫还未入驻”；导航顺序正确，各页面对照小鸡专注参考设计；提醒权限被拒绝时仍可完成核心离线流程。
