## 0.2.2 编辑弹窗与软件键盘（2026-11-15）

通过 `scripts/sheet-keyboard-smoke.mjs` 在 Android 15 专用模拟器复现旧版编辑待办弹窗：软件键盘弹出时可视高度从 820 缩至 549 CSS 像素，默认垂直居中和 `90dvh` 上限使顶部从 41 移到约 27.45，收起后移回。模拟器内置输入法实际窗口高度为 0，不可用于验收；改用官方 OpenBoard Release 的真实键盘，测试工具仅安装在专用模拟器，不随产品分发。

修复将共享弹窗定位到距应用可视区顶部 20 CSS 像素，保留随键盘调整的最大高度与内部滚动；标题/关闭按钮固定在弹窗顶部，打开弹窗时锁定背景滚动，横屏极小高度下将备注框收紧为 48 CSS 像素。文字、数字和备注键盘分别验证，弹窗顶部位移为 0，背景滚动为 0；编辑后保存并重新加载，内容持久化正确。竖屏、横屏以及系统字体缩放 2.0 检查通过。14 项业务测试、TypeScript、生产构建与 APK 打包通过。本轮没有重复执行与 CSS 修复无关的 20 项历史安卓仪器测试。

新增脚本要求真实键盘至少压缩 100 CSS 像素，避免把未显示键盘误报为通过；脚本会恢复本次临时业务数据、字体外的原旋转及键盘设置。测试证据汇总为 [keyboard-verification.json](keyboard-verification.json)。物理手机和各厂商输入法仍可继续反馈。

## 0.1.2 主页面左右滑动

五个主页面按底栏顺序识别左右滑动，在手指松开后直接切换路由，没有页面移动或过渡动画，两端不循环。仅注册在主内容区，按五个主路由精确匹配；专注页和所有已打开的 dialog 不参与。输入控件、图表画布、可横向滚动的局部容器及屏幕左右 24 CSS 像素的系统手势边缘不抢占切页手势。

识别条件为单指、横向位移至少 60 CSS 像素、横向大于纵向位移的 1.5 倍且在 800 毫秒内结束；先向纵向移动的手势保持滚动，取消事件和多指操作会清理本次手势。

Android 15 模拟器新增 `SwipeNavigationTest` 三项实际触摸检查：五页前后依次切换及底栏选中状态、首尾边界和纵向/短距/取消手势、专注页/关于详情/未保存主题表单不切页。750×1688 像素、320 dpi（375 CSS 像素宽）的竖屏配置下，全部 12 项安卓测试通过，包括之前两项底栏回弹检查。14 项业务测试、TypeScript/生产构建、格式检查和 APK 打包通过。证据分别保存为 `artifacts/swipe-navigation/portrait.xml` 和安卓测试构建报告。物理手机的滑动手感仍需安装新包确认。

## 0.1.1 滚动回弹修复

用户反馈在页面上下拖动到边缘时，内容和底部导航一起回弹。Android 15 模拟器通过实际注入触摸事件复现：顶部下拉时，底栏截图区域约 6.23% 的像素发生明显变化。DOM 的固定定位不能阻止 Android 对整个 WebView 施加边缘拉伸。

修复在 MainActivity 中设置 WebView 的 `OVER_SCROLL_NEVER`，关闭整层边缘拉伸。没有拦截触摸事件，也没有禁用页面滚动。

新增 `ScrollLayoutTest` 两项安卓回归测试：对比触摸拖动前与手指尚未松开时的系统屏幕截图，检查顶部、底部的底栏像素变化低于 0.2%；另在仅存在于测试 DOM 的长内容中，验证真实上滑可滚动超过 100 CSS 像素，并再次检查两端底栏稳定。测试内容不写入业务数据。

执行 `.\gradlew.bat :app:connectedDebugAndroidTest :app:assembleDebug --console=plain --quiet`，9 项安卓测试全部通过；14 项业务测试、TypeScript 检查、生产构建与修改文件格式检查通过。版本号为 0.1.1，Android versionCode 为 2。该修复已在模拟器验证，用户截图对应的物理手机仍需安装新包确认。
