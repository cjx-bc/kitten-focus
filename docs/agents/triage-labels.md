# Triage labels

| Canonical role | GitHub label | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 已明确，可交给代理执行 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 不予实施 |

技能提到某个角色时，使用对应 GitHub 标签。
