# 学霸模式前端设计与交互演示

日期：2026-11-15。状态：供用户审阅的交互原型，未接入安卓系统能力。功能依据为[开发规格](focus-control-spec.md)，视觉依据为[界面基准](brand-spec.md)及现有 Vue/CSS。

## 设计方向

模式为现有产品扩展。保留五栏导航、白底、浅灰分组、黑色主按钮、线性图标、圆润计时数字和现有输入框规则。截图用于确认设置结构和功能，不复制背景壁纸、紫色图标、六栏导航或竞品品牌。

Design Read：安卓学习应用的设置与控制流程；手机近距离阅读；安静、克制的黑白灰。布局变化2、动效2、密度5、素材依赖3、品牌忠实度10。重要内容为模式与当前状态，细项分层展开，不在主面板堆满六项强制性说明。

视觉参数：主文字 #222222、辅助文字 #737378、浅灰面 #F5F5F5、边线 #EAEAEA、橙红提示 #EF4E36；4/8px间距，页面边距24px；标题26–28px、行标题16px、正文14–15px、辅助12–13px；卡片20px、面板28px、按钮胶囊；触控目标48px。中文沿用系统无衬线，数字用本项目离线 Nunito。阴影只用于面板层级，状态变化约180ms并支持减少动效。

## 信息结构

| 页面 | 主要内容 | 交互重点 |
| --- | --- | --- |
| 待办首页 | 原有主题与待办；学霸模式状态入口；锁机次入口 | 保留开始按钮；点击入口才展开设置 |
| 学霸模式面板 | 学霸、严格、通知三个开关；全局白名单、增强保护、权限、帮助入口 | 标题与关闭固定，内容内部滚动；各开关独立 |
| 白名单 | 跟随全局/独立设置、搜索、多选、系统App切换、确认保存 | 编辑为草稿，保存生效；小猫和必要例外有明确说明 |
| 提升强制性 | 常规、防关闭、防卸载三个分组，完整六项 | 按项说明用途/授权/恢复；未验证能力有提示，演示不冒称系统已支持 |
| 权限与状态 | 实际权限、控制是否有效、修复入口 | 未授权、已就绪、执行中、失效分别表达 |

| 专注/锁机进行中 | 大号时间、事项、实际保护状态、允许应用/通知摘要 | 严格时无暂停/提前结束；保留帮助和故障恢复 |
| 原生阻挡页 | 当前受限应用、事项、剩余时间、返回专注、临时放行 | 普通模式放行1/3/5分钟；严格时禁用 |
| 休息页 | 五分钟倒计时、上一轮摘要、返回/再次专注 | 明确本轮限制已释放 |
| 帮助 | 模式区别、继承规则、通知、强制性、故障与恢复 | 可展开分组；不隐藏系统限制 |

## 状态和反馈

- 面板偏好开关与实际权限分开；模拟开启需授权的能力时出现解释弹窗，可取消或模拟授权。
- 用户编辑运行中的全局设置，只改变下一轮；页面说明“本轮设置已固定”。
- 白名单过滤不删除已选项，系统App默认收起，确认保存才修改配置，空搜索有恢复入口。
- 开始前核对本轮能力；缺权限提供去授权或明确降级，不静默启动假保护。
- 运行中可演示权限失效、倒计时到期、提前结束、通知释放和进入休息。
- 通知隐藏/释放与设备防关闭在原型里只是效果演示，所有系统授权和应用切换均为模拟，不触发真实安卓设置。

## 前端落地方式

演示使用单文件HTML/CSS/JavaScript，不安装额外前端框架，也不修改当前业务页面。正式落地保持Vue3，提取 StudyModeSheet、AppWhitelistSheet、ProtectionSettings、PermissionStatus、StudyModeHelp 等组件，沿用 Sheet/Icon 和全局设计变量。当前选项、草稿名单、本轮实际状态分开管理；原生能力由Capacitor返回，前端不能自行判定授权或限制成功。

桌面演示中的页面导航、状态模拟和 Tweaks 均为审阅工具，不进入应用正式界面。原型提供标准、舒展、紧凑三档密度，默认标准；可比较设置行高度与阅读密度。演示任务、应用列表、通知数量和时间均为示例数据，不读取手机、项目业务数据或真实通知。

## 演示产物

- [交互演示HTML](prototypes/study-mode-demo.html)：完整单文件，可离线打开。
- 主流程：开启学霸 → 模拟授权 → 编辑白名单 → 配置增强 → 开始专注 → 演示受限应用 → 临时放行/到期 → 休息。
- 辅助流程：待办独立名单、锁机设置和运行、严格倒计时、通知授权、权限失效、帮助和故障恢复。
- 本轮验收目标是用户评价布局、样式和交互是否符合要求，不等同系统能力已实现或安卓真机测试通过。
