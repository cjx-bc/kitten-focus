# 学霸模式 UI 提案与可点击演示

日期：2026-11-15。依据：[完整规格 v2](focus-control-spec.md)、[现有视觉基准](brand-spec.md)与当前 Vue 页面。该提案用于审阅新增界面，没有接入 Android 控制能力。

用户已明确要求：**原有设计风格不要改**。以下以现有源码为唯一视觉基准，v2 替代此前带审阅外框的演示；新增能力通过已有组件和样式扩展。

## 设计判断

采用现有产品扩展（Extension），保留待办 / 日历 / 小猫 / 统计 / 我的五栏导航、主题与子待办结构、计时方式和五分钟休息。新增界面服务于“开始前配好，专注时少打扰”。手机近距离阅读，安静、克制，先看模式与状态，再展开复杂选项。

Design Read：移动端交互原型；布局变化 2、动效 2、信息密度 5、素材依赖 3、品牌忠实度 10。低布局变化对应既有列表和 Sheet；低动效对应约 180ms 状态反馈；中密度对应设置分组与独立子页；素材只使用现有小猫标识、Nunito 和线性图标。

## 页面与主要交互

1. **待办**：标题下紧凑显示“学霸模式 · 未开启 / 待授权 / 已就绪 / 保护中 / 保护失效”。独立锁机为次入口；子待办保留右侧开始按钮，点击任务正文编辑独立白名单。
2. **学霸模式 Sheet**：沿用现有 Sheet 的顶部 20px 位置、四角 26px 圆角和宽度规则，不改为底部抽屉。放学霸、严格、拦截通知三个独立开关；下方进入增强保护、全局白名单、权限状态和帮助。开关改变偏好，开始专注/锁机才执行。运行时明确标注“以下修改用于下一轮”。
3. **白名单**：全屏编辑，搜索和系统应用筛选，多选项和数量，底部固定“确认保存”。取消丢弃草稿。子待办和锁机显式选择跟随全局或独立名单；独立空名单不回退到全局。小猫固定允许，电话、输入法与紧急入口作为必要例外说明。示例应用图标为类型占位，正式读取 Android 安装包图标。
4. **增强保护**：按常规 / 超强力：防关闭 / 超强力：防卸载三组列齐 FORCE-01—06。每项有说明入口、所需权限和支持状态；未经验证不标为已支持。帮助中写清图标、壁纸、最近任务状态的恢复方法。
5. **权限与保护状态**：分开列出用户偏好、授权、连接/服务状态、本轮实际执行、失败原因和恢复入口。返回系统后重新检查。开启新能力先解释用途、影响、本机处理与关闭方法，再提供暂不开启 / 前往设置。
6. **开始前检查**：展示计时方式、时长、名单来源及本轮能力。缺权限时允许去授权，或由用户明确选择本轮降级。严格开关配正计时显示“不适用，仍可正常结束”，不更改计时方式。
7. **专注 / 阻挡页**：保留原有大数字、事项、状态和 84px 黑色圆形暂停 / 60px 浅灰圆形结束按钮。移除新增小猫插图和常驻保护卡片，详情收进一行查看入口。普通暂停不释放保护；严格倒计时不提供暂停和提前结束。阻挡页提供返回专注，普通模式可放行 1/3/5 分钟，一轮最多三次，同时一个应用。
8. **休息**：五分钟倒计时，明确本轮控制已释放；不把“暂停”和“休息”混同。
9. **独立锁机**：名称、时长、名单来源、严格/通知和增强设置；开始前检查，运行时显示剩余时间和故障恢复。与专注/休息互斥。
10. **帮助与恢复**：离线可读的模式区别、名单覆盖、通知与声音、系统边界、服务断连、权限重开、增强影响与恢复。故障恢复撤销额外保护，不将会话伪记为完成。

## 状态设计

“下一轮配置”和“本轮快照”用不同区域表达。正在计时仍可编辑设置，保存后不会改变本轮名单或增加新能力。权限撤回或服务失联保留计时，同时将实际状态显示为失效。

正式实现必须由原生桥返回权限、服务和执行结果；前端不能用偏好开关推断保护成功。通知结束释放、壁纸恢复和防关闭的支持情况仍以设备技术验证为准，原型的模拟结果不作实现证据。

## 前端接入方案

继续使用 Vue / TypeScript / Pinia / Capacitor，复用现有 Sheet、Icon 和样式变量。建议组件为 StudyModeSheet、WhitelistEditor、ForceOptions、PermissionStatus、StartReview、FocusProtectionSummary、LockSetup 和 ProtectionHelp。

状态分三层：持久偏好、编辑草稿、原生会话只读快照。应用列表使用包名作唯一键；缺失应用保留配置并标为未安装；名单采用 `{ source: 'global' }` 或 `{ source: 'custom', packages: [] }` 表达，避免空数组语义混淆。

开始、放行、结束、恢复均交给同一原生协调入口；Vue 仅请求和展示返回结果。计时沿用现有会话依据，不新增第二套业务计时/数据库。原型内的 JavaScript 倒计时仅用于视觉交互演示。
