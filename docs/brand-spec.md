# 小猫专注：界面实现基准

已批准方向：全面参考小鸡专注，功能按 v1-spec.md；无需重新选择视觉方向。

Design Read：安卓学习工具；手机近距离阅读；黑白灰、大留白、圆润计时数字、少量橙红状态强调。新建项目，布局变化 2、动效 2、密度 5、素材依赖 3、参考忠实度 10。

参考文件：references/chickfocus/official-01.jpg（专注）、official-07.jpg（时间轴）、official-08.jpg（统计）。这些是商店图，不把宣传排版放进应用。小猫页仅显示已定占位文字，图标采用统一线性矢量图标。

实现近似参数：背景 #FFFFFF，次级面 #F5F5F5，主文字 #222222，次文字 #737378，边界 #EAEAEA，强调 #EF4E36。4/8px 间距，页面边距 24px，卡片圆角 20px，按钮胶囊圆角；无装饰渐变。正文系统中文无衬线，数字使用离线 Nunito 可变字体，不宣称它是参考产品实际字体。标题 26px，正文 15px，辅助文字不小于 12px，触控目标至少 48px。状态切换使用 150–220ms 淡入，尊重减少动态效果。

2026-11-14 用户选定输入框 A 方案：常态浅灰底 #F5F5F5、1.5px 浅灰边界 #ECECEE；聚焦时白底、贴合控件的细灰边框 #838388，不使用外围橙红圈。文字、数字、日期、下拉选择和备注采用同一规则，聚焦不改变控件尺寸。键盘操作按钮、链接和复选控件时保留灰色焦点提示；错误提示继续使用原有警示色。

数据库推荐中的营销页结构、衬线字体与蓝色主按钮不符合已确认参考，未采纳。未对照到的主题切换、背景和音频功能不伪装成已有能力；界面阶段按参考可见状态完善。

2026-11-27 v2（0.3.x+）全细节复刻扩展（见 [cat-companion-plan.md](cat-companion-plan.md)）：
1. 百兽插画体系继承 `AppMark` 黑猫剪影母体：以 `#222222` 墨黑块面（或 `#FFFFFF` 白底配 `2.5px #222222` 描边）与纯白大圆眼圈为统一基底，每只角色至多叠加 1–2 个取自既有 `THEME_COLORS` 的低饱和纯色块，支持通过 CSS 变量零体积切换毛色皮肤。
2. Android 原生全屏覆盖层（`FocusBlockOverlay`）移除旧暖米色硬编码，全量对齐本基准黑白灰 Token 并复用离线 `Nunito` 字体渲染计时数字，确保前端与原生遮罩视觉零断层。
3. P1（0.4.0）开放纯黑深色模式（背景 `#111113`、次级面 `#1C1C1E`、主文字 `#F5F5F7`、次文字 `#8E8E93`、边界 `#2C2C2E`、强调 `#EF4E36`），对标 `official-10.jpg` 深色视觉。
