# 采用《小鸡专注》单局孵育与高水位纯函数推导，融合三档防分心保护阶梯

v2（0.3.x+）宠物养成放弃早期设想的“双货币（经验值+金币）+ 家具商店装修 + 课表耦合”重度 RPG 路线，全面复刻《小鸡专注》的单局孵育收集模型（完整规格见 [cat-companion-plan.md](../cat-companion-plan.md)）：根路由首屏直达专注待机页（原有待办管理收纳于左上标签胶囊，原有日程与课表无损保留于时间轴页顶栏切换入口），每次有效计时专注实时分三阶段养大上阵动物并放入「一周农场」散步。

养成与收集状态不单独持久化可变余额或解锁表，而是以 `FocusRecord[]` 为唯一事实源按时间顺序纯函数回放推导当前 `好感` 与历史最高峰 `peakAffection`：正常专注增加好感，倒计时逾 10 秒后悔期放弃或离开超时扣除 5 点好感（下限为 0），动物解锁依据 `peakAffection` 与成就里程碑判定，从而在保留“挂了扣好感”损失厌恶张力的同时保证已解锁动物永不回锁，并在删除记录或导入备份后 100% 自动一致；时间轴手动补录（`source: 'manual'`）在推导入口硬隔离，仅计入统计时长而不产出好感、动物或成就。

防分心能力按权限轻重整合为互不冲突的三档阶梯：① 默认开箱即用的 0 敏感权限「轻看护」（亮屏切去非白名单应用 10 秒未归判本轮失败，熄屏锁屏与通话豁免）；② 复用既有 `StudyModeSheet` 与 `FocusBlockOverlay` 的 Android 原生「学霸模式」（白名单放行不死宠，受限应用 0ms 全屏遮挡拦回，遮罩视觉统一对齐前端黑白灰与 `Nunito` 数字）；③ 遵守 ADR 0004 的「独立锁机」（不进专注统计、不涉好感与宠物生死）。
