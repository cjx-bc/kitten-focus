# 专注后的五分钟休息

状态：纳入 v0.2.3 发布。用户已授权提交、推送和发布，并明确跳过本次测试；未进行安卓模拟器或真机验证。

## 已确认的交互

- 倒计时正常到点、正计时主动结束后，自动休息五分钟。专注 25 分钟、自定义任意正整数分钟，以及正计时，休息时长均固定为五分钟。
- 倒计时提前结束后不自动休息，结果页提供“休息 5 分钟”和“返回待办”。中断和零时长不自动休息。
- 休息页为独立全屏页面，隐藏底部导航，显示上一条待办、实际专注时长、剩余休息时间和“退出休息”。没有暂停操作。
- 点击“退出休息”、顶部返回或安卓返回键，先显示退出确认。点击“确认退出”后停止倒计时、撤销提醒并返回待办；选择“继续休息”或关闭确认弹窗，倒计时继续。
- 休息结束后显示“休息结束，准备好再开始”，提供“再次专注”和“返回待办”。下一段专注由用户手动开始；再次专注沿用上一条待办、计时方式和目标时长。
- 专注记录在结束时保存，休息不增加专注次数或时长。退出休息不删除专注记录。

## 计时与持久化

休息状态独立于业务数据和专注记录。安卓保存到本地 SQLite，并用单调时钟计算同次开机内剩余时间；后台闹钟处理到点提醒，声音、振动沿用现有设置。设备重启后根据保存的到期时间恢复。延迟处理专注完成时，从实际到点时刻计算休息，不会在晚打开应用时重新赠送五分钟。

网页预览用 IndexedDB 持久化截止时间；重新加载后恢复剩余休息。恢复业务备份时清理正在进行的休息和旧提醒。到点只把休息标为完成，不会自动启动下一次专注。
