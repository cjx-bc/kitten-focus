# 番茄 ToDo：待办与计时形式调研

核验日期：2026-11-15。范围：中国应用「番茄 ToDo」，开发者上海盼推科技有限公司。本文区分当前官方公开证据、历史实机使用证据与尚未核实的线索；未安装或运行应用，未启动安卓模拟器。

## 可用于需求讨论的结论

番茄 ToDo 的待办设置至少应分成两个维度理解：**计时怎么走**，以及**待办以什么目标或周期衡量完成**。学霸模式、自习室、时钟外观则是另一些功能，不能作为计时方式并列。这个分层由当前官网展示与历史一手评测相互印证，但不代表所有类型与计时方式都能任意组合。[S1][S2][H1][H2]

| 维度 | 可以确认的内容 | 证据强度与边界 |
| --- | --- | --- |
| 当前计时方式 | 倒计时、正计时 | 官网当前正文直接列出两者；官网卡片也出现正计时标签。[S1][S2] |
| 番茄钟 | 可配置专注时长与休息时长 | 当前 iOS 与安卓官方商店介绍均支持；不能把番茄钟当成第三种独立的走时方向。[S3][S4] |
| 时长目标 | 可以用分钟数表示习惯进度 | 官网图中一个习惯项目的单次计时为 25 分钟，当日累计目标为 40 分钟，二者不同。[S2] |
| 数量目标 | 可以用非时间数量衡量习惯进度 | 官网出现按周计算的读书本数；官网正文也用每日次数举例。可确认存在数量度量，未证明任意单位均可自由输入。[S1][S2] |
| 重复与习惯周期 | 当前官方展示包含每日、每周；安卓介绍明确提到重复选项 | 不足以证明自定义星期、隔日、间隔 N 天、月度或更多周期规则。[S2][S4] |
| 历史待办类型 | 普通番茄钟、定目标、养习惯 | 2019、2020 年的一手评测/实机图可见。当前官网仍展示习惯，但未公布完整创建表单；不能直接宣称当前两平台仍使用同一组名称。[H1][H2][S2] |
| 历史第三种方式 | 不计时 | 2019 年原始评测与历史界面可见；本轮未找到当前官方说明确认其名称和操作规则。[H1][H2] |

## 当前官方证据能说明什么

### 计时方式、单次时长与累计目标

官网将正计时和倒计时归入计时功能。官网主图同时展示一个正计时习惯，以及一个以 25 分钟为单次设置、按当日累计分钟数追踪进度的习惯。这足以确认「计时方式」与「习惯目标」可以同时存在，且单次计时时长不等于当天目标总时长。[S1][S2]

当前 iOS 商店把番茄时间和休息时间列为可配置项；安卓商店也如此描述。因此它支持调整工作/休息节奏，不能把它概括成只支持固定 25/5 分钟。官方当前文案未给出所有可选时长、最小/最大值、默认值及长休息规则。[S3][S4]

### 目标与重复

官网主图中，读书习惯按周显示完成本数，锻炼习惯按日显示累计分钟数。这证明目标的度量不只限于专注时长；但不能仅凭显示的「本」反推单位编辑器完全自由，或断言计数一定自动增加。[S2]

安卓商店介绍提到重复选项，但没有展开规则。当前能直接看见的周期仅为官网图中的日、周；「每天重复」也不应被描述为一种计时方向。[S2][S4]

### 附加功能与边界

| 功能 | 官方可确认的作用 | 不应混淆的项目 |
| --- | --- | --- |
| 学霸模式 | 减少其他 App 干扰；iOS 更新文案提到白名单和拦截 | 专注限制策略，不是倒计时/正计时之外的计时方向。[S3][S4] |
| 自习室 | 与朋友共同学习/专注 | 社交陪伴场景，不是待办的目标类型。[S3] |
| 悬浮窗 | 让正在进行的专注计时显示在其他界面上 | 显示入口，不是新的计时类型。[S3][S4] |
| 午夜模式 | 安卓商店公告说明凌晨开始的新计时可归入前一天，并给出设置入口 | 统计归属规则；官方当前公告未说明精确小时区间。[S4] |
| 未来/日期倒计时 | 官方隐私政策把它与待办、历史专注数据并列列举 | 它是独立的数据/功能对象，不能与一段专注会话的倒计时混为一谈。[S5] |
