小猫专注 0.2.0 内测候选版，新增应用内更新。

- “我的 → 检查更新”：显示更新说明、版本与包大小。
- 每日后台检查，有新版只显示红点，可跳过更新。
- 支持系统后台下载、取消和重试，计费网络先确认。
- 专注未结束时暂缓下载和安装。
- 安装包校验后交给系统确认安装。
- 升级前保留最近三份本地恢复副本，可导出、恢复。

首次需手动覆盖安装本版一次，后续才能从 App 内更新。不要卸载旧版。沿用此前内测签名，包名 com.xiaomao.focus，versionCode 6。
