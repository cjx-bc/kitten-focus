# 小猫专注 v0.3.1 · 稳定性修复、SAF 导出加固与 Android 16 实机优化（内测版）

- **SAF 导出闪退与弹窗顺序修复（`CatFocusPlugin.java`、`SettingsView.vue`、`exportPng.ts`）**。将日历一周四色分布图 PNG、一周农场打卡图 PNG 与设置页 JSON 备份的原生 SAF 导出数据改为先落盘至应用缓存临时文件，在后台 `EXPORT_IO` 线程通过 `"wt"` 模式写入 `OutputStream` 并回收临时文件，彻底消除大数据跨 Binder 传递触发的 `TransactionTooLargeException` 闪退；同步将导入读取移出主线程，并在设置页呼起系统文件选择器前关闭单层 `<Sheet>`、静默处理用户主动取消。
- **白噪音焦控、API 36 开机 FGS 与即时通知修复（`WhiteNoisePlayer.java`、`WhiteNoisePolicy.java`、`FocusKeepAliveService.java`、`Reminders.java`）**。修正音频永久失焦状态（`AUDIOFOCUS_LOSS`）处理与通知栏/用户重选曲目恢复策略，消除失焦循环抢焦点；Android 14+ 开机恢复专注（`fromBoot=true`）仅申请 `FOREGROUND_SERVICE_TYPE_SPECIAL_USE` 并保留降级兜底，避免 Android 16（API 36）开机无音频焦点权限下 `mediaPlayback` 前台服务异常，常规专注开关白噪音仍实时动态升级至 `specialUse|mediaPlayback`；为常驻专注通知增加 `FOREGROUND_SERVICE_IMMEDIATE`，消除开启前 10 秒系统延迟展示问题并确保 `<10s` 通知「结束」正确执行无责撤销（`finishFromNotification` → `"cancel"`）。
- **原生专注覆盖层排版、轻看护边界与锁竞争优化（`FocusBlockOverlay.java`、`FocusControl.java`、`AndroidAntiCloseSystem.java`、`LeaveAppWatcher.java`、`MainActivity.java`、`UsageAppMonitor.java`、`App.vue`）**。修复覆盖层 `Nunito.ttf` 变量字重（`'wght' 850`）与普通专注提示文案，限定 `<10s`「取消」仅对非严格倒计时生效，并为白噪音/白名单子面板新增紧凑头部与 `ScrollView (fillViewport=true)`，确保全部选项与音量条完整不裁剪且保持 `48dp` 触控高度；拆分 `FocusControl.observeSessionState()` 隔离慢速 Binder/PackageManager IPC 出 `synchronized (store)` 锁，缓存 `appLabel()` 30 秒并将 `extractSnapshot()` 与 `observeNavigationFocus()` 移至后台线程；修复 `LeaveAppWatcher` 异步竞态与豁免边界。
- **手动补录统计口径对齐与前端边界修复（`statistics.ts`、`StatisticsView.vue`、`CalendarView.vue`、`FocusView.vue`、`RestView.vue`、`PetPickerSheet.vue`、`farmCard.ts`、`stream.wav`、`UpgradeBackups.java`）**。按 `GLOSSARY.md` 与 `ADR 0005` 口径限定手动补录（`source === 'manual'`）仅计入时间轴、时长与时段分布，不计入专注次数、平均时长、提前结束次数与好感度；修复跨天时间轴分片统计、统计页当年 365 热力图锚点与闰年 1 月 1 日边界、`PetPickerSheet` 锁定态文字对比度、`RestView` 过时番茄循环守卫及升级备份记录字段校验，并保留原有待办、日程、课表与 Schema-1 备份完全兼容。
