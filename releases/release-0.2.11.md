# 小猫专注 v0.2.11 · 单段原生眨眼小猫开屏（内测版）

- **单段原生「歪头抖耳 Wink」开屏动画**：在 Android 12+ 设备上采用纯黑白纯猫头矢量动画（`avd_cat_wink` + `cat_splash_head`，780ms 歪头、右耳轻抖、呆毛晃动与单眼眨眼）配合底部品牌标识「小猫专注 / 专注此刻，陪小猫一起长大」；Android 7–11 自动静默降级为纯猫头静态图标。
- **消除两段闪屏与白屏割裂**：`MainActivity` 接入 `androidx.core.splashscreen.SplashScreen` 与 `SplashCoordinator`，保持原生开屏直至 Vue 首帧完成渲染（最长 1800ms 超时兜底）后 180ms 丝滑淡出，同时在原生环境下抑制前端 `.boot` 第二段文字闪屏；纯网页预览保留 `.boot` 与新版副标。
- **高频专注与辅助模式直通**：当检测到正在进行的专注 / 休息 / 锁机会话（或系统通知拉回 `/focus`、`/lock`、`/recovery`）或系统开启减少动态效果时，跳过 780ms 等待并在前端就绪后直接进入目标页面。

版本号为 `0.2.11`，versionCode 为 `17`。沿用 `com.xiaomao.focus` 和原内测签名。已安装的用户可从「我的 → 检查更新」升级，或直接覆盖安装 APK 保留本地数据。

本次通过 20 个测试文件 / 161 项宿主单元测试、5 个 E2E 文件 / 32 项浏览器及 UX 门禁检查、TypeScript/Vite 生产构建、安卓 APK 构建、5 项安卓 JVM 单元测试、安卓仪器测试编译检查及包名、签名和完整性校验（`prepare-update.py`）。未运行模拟器与真机回归测试。
