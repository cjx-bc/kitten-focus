# 小猫专注 v0.2.8 · 待办页优化（内测版）

- 空页面可直接开始默认时长的专注，也可以一次保存第一个待办和所属主题。
- 点击待办卡片即可开始专注，使用「⋯」编辑。应用限制默认收起，专注、锁机或休息进行时会提示何时能开始新的专注。
- 修复排序后保存会还原、快速点两次主题只切换一次的问题。删除主题前可明确选择移动或一并删除下属待办。
- 首页一次汇总今日专注，保留跨午夜后实际发生的时长。已同步更新白名单、业务回归和软键盘验收脚本的待办入口。

版本号为 `0.2.8`，versionCode 为 `14`。沿用 `com.xiaomao.focus` 和原内测签名。已安装的用户可从「我的 → 检查更新」升级，或直接覆盖安装 APK 保留本地数据。

本次通过 157 项宿主测试、浏览器待办流程检查、TypeScript/Vite 构建、安卓 APK 构建、安卓 JVM 单元测试及包名、签名和完整性校验。按发布要求跳过模拟器测试。
