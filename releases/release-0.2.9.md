# 小猫专注 v0.2.9 · 学霸模式改版与新图标（内测版）

- **学霸模式全面改版**：重组为「总开关 + 应用限制 / 严格模式 / 免打扰 + 授权与权限中心」，将原 6 项防退出类增强保护统一并入严格模式，并将「锁机时限制主界面入口」移入独立锁机配置页。
- **专注页锁定与安全出口**：开启学霸模式开始专注后，专注页返回键、Android 系统返回与路由跳转均锁定在专注页，同时保留使用帮助、紧急与必要交互、故障恢复入口，结束后自动解锁。
- **推荐默认与自定义记忆**：支持「首次推荐默认 + 记住自定义 + 一键恢复默认」，兼容旧版本保护偏好迁移及前后端本地备份校验与恢复。
- **更细粒度的原生保护控制**：支持独立开关「允许临时放行」与「白名单应用通知照常显示」，优化无障碍服务对系统界面及当前输入法临时浮层的识别。
- **全新应用图标与交互打磨**：更新小猫自适应矢量/单色应用图标、Web 图标与「我的」页品牌标识；待办编辑弹窗新增备注折叠与时长快捷排布优化。

版本号为 `0.2.9`，versionCode 为 `15`。沿用 `com.xiaomao.focus` 和原内测签名。已安装的用户可从「我的 → 检查更新」升级，或直接覆盖安装 APK 保留本地数据。

本次通过 19 个测试文件 / 175 项宿主测试、TypeScript/Vite 生产构建、安卓 APK 构建、安卓 JVM 单元测试、安卓仪器测试编译检查及包名、签名和完整性校验（`prepare-update.py`）。未运行模拟器与真机回归测试。
