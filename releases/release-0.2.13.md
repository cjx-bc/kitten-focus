# 小猫专注 v0.2.13 · 启动自动查更新、前台保活与冷静防焦虑打磨（内测版）

- **每次启动自动检查更新（Option A 零打扰）**：每次冷启动（及 60 秒进程内冷却外的恢复）自动在后台静默检查新版本；发现更新后仅在空闲主屏且无其他弹窗时弹出单层版本卡片，点击「稍后再说」后同一 `versionCode` 不再主动弹窗打扰，仍保留「我的」红点与手动检查入口；下载过程支持「收起，后台继续下载」。
- **Android 前台保活服务（`FocusKeepAliveService`）**：专注或独立锁机进行中自动启用 `specialUse` 前台保活服务，并直接复用现有专注常驻通知（`FOCUS_ID = 40`），不额外弹出第二条通知；结束、重启或恢复后立即停止，平时不在后台耗电。
- **「后台运行不限制」授权与各品牌防清理指引**：在「我的 → 提醒与声音 → 系统提醒与后台」、学霸模式「权限与使用帮助」与 `/permissions` 诊断中心提供冷静、零红标焦虑的电池优化放行入口（支持 1-tap 系统弹窗与 3 级降级跳转），切回自动刷新状态；在 `/help` 新增五大安卓品牌单行设置路径清单，并依据 ADR-0004 如实说明能力边界。
- **Impeccable 前端体验打磨**：统一更新卡片信息层次、数据备份安心提示、限高可滚更新说明、可选权限卡片对比度与文字选区细节，延续极简素净黑白风格。

版本号为 `0.2.13`，versionCode 为 `19`。沿用 `com.xiaomao.focus` 和原内测签名。已安装的用户可从「我的 → 检查更新」升级，或直接覆盖安装 APK 保留本地数据。

本次通过 22 个测试文件 / 169 项宿主单元测试、5 个 E2E 文件 / 32 项浏览器及 UX 门禁检查、`impeccable detect --json --changed`（0 告警）与 390px/320px 渲染巡检、TypeScript/Vite 生产构建、安卓 APK 构建、11 项安卓 JVM 单元测试、安卓仪器测试编译检查与包名、签名和完整性校验（`prepare-update.py`）。未运行模拟器与真机回归测试。
